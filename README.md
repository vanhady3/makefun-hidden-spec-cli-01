mend is one command-line tool that applies AI-written edits in four formats
to a tree of text files: unified diffs (often with wrong line numbers),
SEARCH/REPLACE blocks, V4A patches, and text-editor tool calls as JSON.
It finds the lines an edit names even when the model drifted their
whitespace or indentation, and changes every file or none.

Built for the make.fun `hidden-spec-cli-01-run-20261122` competition
("Build mend, one patch tool for every AI edit format").

## Run it

```sh
node main.ts [options] [PATCH]
```
